# 🇹🇭 BOT 4: Thai Stocks Pullback & R-Multiple Trading System

ระบบสแกนหุ้นและบริหารความเสี่ยงอัตโนมัติสำหรับหุ้นไทย (SET) ออกแบบตามกลยุทธ์ **Trend Leader + Volatility Contraction (VCP) + Support Confluence First Retest + Board Lot (100 หุ้น) Risk Management**

---

## 💰 ข้อมูลพอร์ตและการตั้งค่าระบบ
* **วงเงินพอร์ตโฟลิโอ:** 1,000,000 บาท
* **งบความเสี่ยงต่อไม้ (0.5%):** 5,000 บาท (สูงสุด 1% = 10,000 บาท)
* **เพดานเงินลงทุนต่อตัว:** ไม่เกิน 20% (200,000 บาท)
* **การเคาะซื้อขาย:** บังคับปัดเศษลงเป็น **Board Lot 100 หุ้น** เสมอ
* **ระยะตัดขาดทุน (Stop Loss):** หลุดจุดต่ำสุด - 1 ถึง 2 ช่องราคาตามตาราง Tick Size ของตลาดหลักทรัพย์แห่งประเทศไทย (SET)
* **เป้าหมายกำไร:**
  * **3R:** ทยอยขายทำกำไร 50% + เลื่อน Stop Loss บังทุนทันที
  * **5R:** ทยอยขายทำกำไรก้อนที่สอง
  * **Runner:** รันเทรนด์ต่อด้วย Daily EMA 9 จนกว่าแท่งวันจะปิดหลุดเส้น
